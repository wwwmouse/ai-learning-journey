# 学习总结：scikit-learn 分类实战

## 学习内容

### 数据预处理

- `pd.read_csv` 读数据
- `df.drop` 删无用列（axis=1 是删列）
- `fillna` 填缺失值（中位数比均值更稳健，不受异常值影响）
- `LabelEncoder` 文字转数字（fit 先扫描，transform 再转换）
- `StandardScaler` 标准化（fit_transform 训练集，transform 测试集——绝对不能用反）
- `train_test_split` 切数据（stratify 保持标签比例一致，random_state 固定随机性）

### 模型训练

- sklearn 的统一范式：选模型 → fit → predict → 打分
- 逻辑回归：线性、迭代求解（max_iter）、稳定 baseline
- KNN：不训练、靠邻居投票、样本不均衡时偏向多数类
- 决策树：问答题树结构、可解释性强、容易过拟合
- 随机森林：多棵树投票、抗过拟合、能输出特征重要性

### 评估

- 准确率会骗人（样本不均衡时全判多数类也能高分）
- 混淆矩阵告诉你模型在哪里犯错
- 精确率 vs 召回率是对立的：想少误报就牺牲召回，想少漏报就牺牲精确
- 交叉验证比单次划分更可信

### 调参

- GridSearchCV 自动搜索最佳参数组合
- `cv=5` 的意思是训练集内部再切 5 份轮流转
- 调参提升有上限——数据量和特征质量决定天花板

## 遇到的最大困难

理解 train_test_split 返回的 X_train、X_test、y_train、y_test 四个变量的关系。搞明白之后整理了这张表：

| 变量 | 给模型的角色 |
|------|-------------|
| X_train | 训练用题目 |
| y_train | 训练用答案 |
| X_test | 考试题目 |
| y_test | 标准答案（藏起来，最后对答案用）|

## 最大的收获

调参后准确率 80.2%，存活 recall 始终 66%。认识到继续调参不如构造新特征——这是从"调包侠"迈出的第一步。
