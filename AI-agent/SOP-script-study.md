# 分析一个脚本（SOP）

> **定位**：这是一份**分析脚本的辅助流程**，不是考核清单。
> **用途**：拿到一个新脚本后，快速弄清它做什么、哪几段值得读、哪些可以跳过。
> **依据**：课程 `docs/HOW_TO_USE.md`——只取其中与"读懂"相关的部分。

---

## 0 与培养方案的关系

| 来源 | 内容 | 在本 SOP 的位置 |
|---|---|---|
| 课程·**六步学习循环** | 看成果 → 直接执行 → 选小改动 → 先猜 → 再跑 → 说出原因 | 只取**前两步**（第 1 节）；后四步是动手改代码，不在本流程内 |
| 课程·**每题做完的三句话** | 为什么这样写 / 拿掉会怎样 / 真实环境还缺什么 | 第 5 节，原样保留 |
| **本 SOP 补充** | 按重要度分层（⭐🟢🟡⚪）及对应的读法 | 第 2、3 节 |

一句话：课程管"怎么学"，本 SOP 只提供一个"怎么把脚本读明白"的轻量流程。

---

## 1 定位脚本（5 min）

### 1.1 先分清类型

| 类型 | 关注点 |
|---|---|
| `starter*.py`（产品代码） | 数据流、控制流、边界 |
| `test*.py`（验收单） | 钉住哪些契约、哪些没覆盖 |

### 1.2 找入口、出口与外部依赖

- **入口**：产品代码看 `if __name__ == "__main__":`；测试看各测试函数里的调用点
- **出口**：`return` 出来的是什么（原始值 / dict / None）
- **外部依赖**：调了几次模型 / 网络 / 文件，调用点集中在哪个函数

---

## 2 按重要度分层（10 min）— 本 SOP 的主要工具

| 档 | 分类依据 | 读法 |
|---|---|---|
| ⭐ 核心 | 删了脚本就不转；换语言/框架仍成立 | 逐行读，连同它前面几条注释一起读 |
| 🟢 必读 | 机制所在（schema / allowlist / 验证 / 控制流） | 记契约：输入、输出、失败形式 |
| 🟡 看关键 | 只有外层几行是关键知识 | 只看外层（如 `try/except`） |
| ⚪ 可跳过 | 具体业务、环境胶水 | 黑盒，记一行签名 |

两个分类问题：

1. **删掉它，脚本还能跑吗？**（能 → 不是核心逻辑）
2. **换个场景/语言，这段还成立吗？**（不成立 → 是业务细节，不是机制）

**经验比例**：学习用的脚本里，通常一半以上行数属于 ⚪。若发现几乎每行都重要，多半是还没分完层，可以先往下读、回头再分。

---

## 3 只深读 ⭐ 和 🟢

- ⭐：读完要能说出"它每一步在改什么、靠什么决定下一步"
- 🟢：只记三样——**输入、输出、失败时返回什么**
- 🟡：只看"错误怎么交给上一层"这类外层逻辑
- ⚪：一行黑盒签名，不进去

---

## 4 读完通常能说清的几件事（自查用，不打分）

- 它做什么：输入是什么、输出给谁
- 哪些数据在函数之间传递、由谁持有、在哪里被修改
- 什么时候会停；出错时走哪条路
- 哪几条结论换语言、换框架仍然成立
- 它**没有**做什么（重试、超时、观测、鉴权…）

说不清的**不需要回头重读整章**，只补那一处就够。

---

## 5 收尾三句话（课程要求）

1. **为什么这样写？**
2. **拿掉它会怎样？**
3. **真实环境还缺什么？**（auth / eval / observability / retry / 人工核准）

---

## 附 A：卡住怎么办

1. 看终端最上面第一个真正的错误，不要只看最后一行
2. 读本题成功条件与失败的那条测试名
3. 仍看不懂 → 记一行疑问，往下走（概念会在后续练习重复出现）

## 附 B：常见坑

| 坑 | 症状 | 对策 |
|---|---|---|
| 行号引用漂移 | 注释里的行号指到别的代码 | 用函数名引用 |
| 诊断代码抢兜底 | 本该报"没点单"，却先 `TypeError` | `print` 放进 `if` 守卫 |
| 相似变量用错 | `assistant` 写成 `final_assistant` | 入历史前打印确认 |
| 测试全绿但行为已变 | mock 绕过了真实依赖 | 必须补跑真机 / eval |

## 附 C（可选）：把理解写进脚本

只写**日后回看才有价值、又不容易重新推导**的东西：

- 开头导语 3–6 行：**链路**（谁调谁、几轮）、**状态**（哪些数据跨调用存活）、**出口**（有几种、各是什么）
- 关键函数前标**重要度**（⭐🟢🟡⚪）
- **禁止写行号**，用函数名引用；注释只答"为什么"，不复述代码

---

**时间盒**：单脚本 ≤ 45 分钟。超时记一行疑问往下走——同样概念会在后续练习重复出现。
